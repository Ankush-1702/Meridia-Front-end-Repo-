# How to log in with a verification code (MFA)

If two-step verification is turned on for your account, you must enter a one-time code after your password.

## Before you begin
Complete steps 1–5 of **How to log in**. The MFA screen appears automatically after **Sign in**.

## Steps
1. On the **Verify your identity** screen, check your email for a 6-digit code. **[CONFIRM: delivery is email per the screen text "Enter the code sent to your email"]**
   `[SCREENSHOT 1: Verify your identity screen]`
2. Type the code in **Verification Code** (digits only, 6 characters).
3. Click **Sign in**.
4. You are taken to the Meridia home page.

## Good to know
- The code is valid for **10 minutes**.

## Troubleshooting
| Problem | What to do |
|---|---|
| "Code invalid. Please try again or **Send a new code**" | Re-check the digits or click **Send a new code**. |
| "Code expired." | Click **Send a new code** and use the latest email. |
| No email received | Check spam/junk, then click **Send a new code** under the field. |
