# How to reach Custom Zones from the Library

1. In the Library, open the **Zones** tab.
2. Click **Custom Zones** (top right) to see and manage your custom zones.
   `[SCREENSHOT 1: Zones tab with Custom Zones button]`
3. To create one directly, click **Add** → **Custom zone** (under **Create new**).

Full steps will be covered in the Zones / Custom Zones module.
