# How to turn notification pop-ups on or off

Control whether Meridia shows pop-ups when new notifications arrive.

## Steps
1. Open **My Profile**.
2. In the **Notifications** section, find **Show Notification Pop-ups**.
   `[SCREENSHOT 1: Notifications section with toggle]`
3. Switch the toggle **on** to see pop-ups in the bottom-left corner of the screen, or **off** to hide them.
4. Click **Save Changes**. (**Reset** reverts an unsaved change.)

## Good to know
- Turning pop-ups off dismisses any pop-ups currently showing.
- Notifications still appear on the **Notifications** page either way.
