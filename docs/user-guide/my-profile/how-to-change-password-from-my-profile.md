# How to change your password (while signed in)

Change your password from My Profile using a one-time code sent to your email.

## Before you begin
- You need access to the email inbox registered with your account.
- The code is valid for **10 minutes**.
- You will be signed out when the change is complete.

## Steps
1. Open **My Profile**.
2. Scroll to **Security** → **Password Reset** and click **Reset Password**.
   `[SCREENSHOT 1: Security section – Reset Password button]`
3. Meridia emails you a code ("OTP sent successfully") and shows **Verify your identity**.
4. Enter the 6-digit code in **Verification Code**.
   `[SCREENSHOT 2: Verify your identity form]`
5. Enter a **New Password** that meets all rules (hover the (i) icon):
   at least 8 characters, 1 number, 1 special character, 1 uppercase and 1 lowercase letter.
6. Re-enter it in **Confirm New Password**.
7. Click **Reset Password** (the button is enabled once all fields are valid).
8. "Password reset successfully. Logging you out..." appears. Sign in again with the new password.

## Troubleshooting
| Problem | What to do |
|---|---|
| "Code invalid. Please try again or Send a new code" | Check the digits, or click **Send a new code**. |
| "Code expired." | Click **Send a new code**. |
| "OTP already sent" | You requested a code in the last 10 minutes – use that email. |
| "This Password does not match." | Make both password fields identical. |
| Changed your mind | Click **Cancel**. |
