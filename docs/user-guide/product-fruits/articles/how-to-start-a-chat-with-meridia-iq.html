Open Meridia IQ, type a question and read the answer in a chat.

Before you begin

  • Meridia IQ appears only for users whose account has access to it. If you do not see Meridia IQ in the left sidebar, ask your administrator. [CONFIRM: wording for how access is granted]
  • Expand the left sidebar if it is minimised (use the Expand button at the top).

Steps

  1. In the left sidebar, find the Meridia IQ section.

    📷 Screenshot 1: Left sidebar with the Meridia IQ heading and New Chat button

  2. Click New Chat. The Meridia IQ page opens with the heading "Turn Maritime Data Into Actionable Insights".
    • If the sidebar is minimised, click the New Chat icon instead.
  3. Read the examples under I can help you with things like: for ideas. They are examples only and are not clickable.

    📷 Screenshot 2: Welcome screen with the six example questions

  4. Click the message box at the bottom. It shows "Ask anything about vessels, ports or zones".
  5. Type your question.
    • Press Shift + Enter to start a new line.
  6. Press Enter, or click the round arrow button, to send.

    📷 Screenshot 3: Message box with typed question and arrow send button

  7. Wait for the answer. A "Thinking..." message appears, followed by changing messages such as "Hoisting the data..." and "Plotting the voyage...".
  8. To ask a follow-up, type in the same box (it now shows "Reply...") and send again.

Expected result

Your question appears on the right and the answer appears below it. The chat is added to the chat list in the sidebar.

Good to know

  • You can also start a chat from an Ask IQ button on a vessel, port or zone. See "How to ask Meridia IQ about a vessel, port or zone".
  • While an answer is loading, the message box is locked. There is no stop or regenerate button.
  • The small circle next to the send button shows how much of your daily token limit you have used. Hover over it to see "% used" and the reset time (UTC).
  • A note under the box says: "Meridia IQ offers insights based on available maritime data. We recommend verifying key information."
