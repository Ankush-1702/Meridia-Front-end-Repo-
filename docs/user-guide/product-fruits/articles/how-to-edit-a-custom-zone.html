Change the name, description or shape of a custom zone you created.

Steps

  1. Open Library > Zones > Custom Zones.
  2. In the zone's row, click the three-dot icon in Actions and choose Edit. The page titled Edit <zone name> opens.

    📷 Screenshot 1: Actions menu with Edit

  3. Change the Name or Description.
  4. Change the shape: edit points or Centre Lat, Centre Long and Radius (m), or draw on the map. The existing shape is shown and the map zooms to it.

    📷 Screenshot 2: Edit page with the existing zone loaded

  5. Click Save Changes. A message confirms Custom zone "<name>" updated successfully! and you return to the list.

Good to know

  • The Polygon / Circle type cannot be changed on an existing zone.
  • You can upload a file to replace the shape, but its type must match ("Zone type must be Polygon" or "Zone type must be Circle"). The name is not overwritten.
  • Save Changes stays disabled until you change something and the form is valid. The validation rules match those in "How to create a custom zone".
  • Cancel leaves without saving.
  • Deleting a zone is not available in the screen [CONFIRM].

Troubleshooting

ProblemWhat to do
An error page shows when opening EditReturn to the list and try again; the zone may no longer exist.
Save Changes is greyed outMake a change and fix any red fields.
