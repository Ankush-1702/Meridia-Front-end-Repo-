Search inside your Library

  1. Open the Library and select a tab.
  2. Type in the search box. Matches are by:
    • Vessels: name or IMO
    • Ports: name or UN/LOCODE
    • Zones: name, sub type or type
    • Fleets: name, number of vessels or description
  3. The item count updates. If nothing matches you'll see No matches – No entities match your search or filter.

Switch between Grid and List

  1. Click Grid or List (top right of the Library).

    📷 Screenshot 1: Grid view

    📷 Screenshot 2: List view with columns

  2. Your choice is remembered next time.

What you'll see

  • Grid cards: name, country flag, IMO (vessels) / UN/LOCODE (ports) / sub type (zones), and a bell icon when notifications are active.
  • List columns:

- Vessels: Name, IMO Number, MMSI, Type, Flag

- Ports: Name, Country, UNLOCODE, Sub Type, Notifications Enabled

- Zones: Name, Country, Type, Sub Type, Notifications Enabled

  • Pagination: use the page controls under the grid to change page or items per page (default 10).
