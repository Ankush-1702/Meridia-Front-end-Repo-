Use the company icon beside an ownership name on a vessel page to run a Beta AI search for that company's contact details.

Before you begin

  • Open a vessel page on the Overview tab and keep the left-hand vessel details panel open.
  • The icon only appears beside a company name that is filled in. Rows showing a dash (-) have no icon.
  • This is a Beta feature. Results are produced with AI and web search and may be incomplete or inaccurate.

Steps

  1. In the vessel details panel, open the Ownership section.

    📷 Screenshot 1: Ownership section expanded in the vessel details panel

  2. Find the company you want, listed under Operator, Registered owner, Technical manager, Ship manager or Group beneficial owner.
  3. Select the small icon to the right of the company name, next to the Beta tag. Its tooltip reads Search Company Details.

    📷 Screenshot 2: Company icon and Beta tag beside an ownership name

  4. Wait while the search runs. The icon turns into a spinner and its tooltip reads "AI searching ... ". The icon is disabled during this time.
  5. When the search finishes, the company details window opens by itself.

    📷 Screenshot 3: Company details window after a completed search

  6. Select Close (the X at the top right) to return to the vessel page.

Expected result

A window opens with the company name, your chosen role for this vessel (for example "Operator for <vessel name> (IMO ...)"), and the details found. See "How to read company details".

Good to know

  • After a search is done, the icon changes to an eye. Its tooltip reads View company details, and selecting it reopens the result without a new search.
  • If the same company appears in more than one ownership row on this vessel, the other rows switch to the eye icon when the first search finishes.
  • Results are kept for the current browser session for up to 24 hours. Use Refresh inside the window to search again.
  • If you closed the window while a search was running, the result is saved and the eye icon appears when it completes. [CONFIRM: whether the window then opens automatically or only the icon changes]
  • A search that takes too long stops after about 2 and a half minutes.
  • This search starts from a vessel's ownership rows only. The Search item in the main sidebar searches vessels, ports and zones, not companies.
  • [CONFIRM: whether this feature is limited to certain accounts or subscriptions. Nothing in the page limits it.]

Troubleshooting

ProblemWhat to do
There is no icon beside the nameThe company name is empty (shown as -). Icons appear only for named companies.
A red message appears saying the search failedSelect the icon and try again. Messages include "Company search failed. Please try again." and "Company search timed out. Please try again."
The icon is greyed with a spinnerA search is still running. Wait for it to finish.
The window says "No reliable results found for this company"See "How to read company details". Verify through official sources.
