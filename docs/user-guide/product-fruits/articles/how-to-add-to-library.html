Find an item in Meridia and save it so it appears in your Library.

Steps

  1. On the Library page, click Add (top right). A menu opens.

    📷 Screenshot 1: Add menu – Find and add: Vessel, Port, Zone / Create new: Fleet, Custom zone

  2. Under Find and add, choose Vessel, Port or Zone. The search window opens.
    • Shortcut: on an empty tab, click + Add items.
  3. Check the correct tab is selected at the top of the window (Vessels, Ports or Zones).

    📷 Screenshot 2: Search window – tabs, search-by dropdown, search box, Filters button

  4. (Vessels and Ports only) Choose what to search by in the dropdown to the left of the box:
    • Vessels: Name or IMO, MMSI, Call Sign
    • Ports: Name, UN/LOCODE, WPI Number
  5. Type at least 3 characters in the search box (zones search by name).
  6. Click Add to Library next to the result you want. The button changes to Added to Library.

    📷 Screenshot 3: Result row with Add to Library button

  7. Repeat for more items, then press Esc or click outside the window to close it. The item now appears in the Library.

Good to know

  • Clicking the result row itself (not the button) opens that vessel, port or zone page instead.
  • Results load as you scroll down the list.
  • To remove an item, open the same search, find it, and click Added to Library again. [CONFIRM: other ways to remove]

Troubleshooting

ProblemWhat to do
"Enter a search term or select a filter"Type at least 3 characters or pick a country/flag filter.
"No results found for …"Check spelling, try another search-by option, or clear filters.
