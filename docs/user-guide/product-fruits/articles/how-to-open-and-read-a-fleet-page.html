Open a fleet from your Library to see its vessels on a map or list, its composition and its recent events.

Before you begin

  • Fleet management must be switched on for your account or user. If it is not, the Fleets tab and fleet pages are not shown to you.
  • You need at least one fleet. To create or change a fleet, see the separate fleet articles.

Steps

  1. Open Library from the main navigation.
  2. Select the Fleets tab.

    📷 Screenshot 1: Library page with the Fleets tab selected, showing fleet cards

  3. Select the card of the fleet you want. Each card shows the fleet name, the number of vessels ("1 vessel" or "N vessels") and the description, if there is one.
  4. The fleet page opens on the Overview tab.

    📷 Screenshot 2: Fleet page header, tabs and Overview map

  5. Check the header. It shows the fleet name and, below it, the vessel count.
  6. Use the breadcrumbs Library > Fleets above the name to go back to your fleets.
  7. Select a tab: Overview, Composition or Events.

    📷 Screenshot 3: The three fleet tabs

  8. On Overview, switch between the map and the vessel table with the two icons at the top right (tooltips Map view and List view). The map is shown first.
  9. On Composition, read the summary cards and charts that break down the fleet. See "How to read fleet composition".
  10. On Events, read the table of recent events for the fleet's vessels. See "How to view fleet events".
  11. To narrow the vessels on Overview, use Vessel Flag, Vessel Type and Vessel Class. If your account includes the MTI score, MTI Score also appears.
  12. To clear your choices, select Reset Filters. It is greyed out until a filter is changed.

    📷 Screenshot 4: Overview filter row with Reset Filters

  13. To reload the vessel data, select Refresh next to "Updated ... ago".

Expected result

You see the fleet's name and vessel count, and can move between the Overview, Composition and Events tabs.

Good to know

  • The tab you are on is kept in the page address (for example ?tab=composition), so the browser Back button returns you to the previous tab.
  • Filters on Overview and Composition are separate. Changing one does not change the other.
  • The Overview data reloads by itself every 5 minutes. Updated ... ago shows its age. The Events tab has its own Refresh.
  • The fleet page has no date range picker.
  • The table view in Overview shows the columns Vessel, IMO, MMSI, Type, Class, Flag, Nav Status, MTI Score (only if you have it), Next Port, Last Reported, Speed and Course. You can sort by any column and search with Search vessels.... [CONFIRM] how each value is sourced.
  • Above the table, "Showing X of Y vessels" tells you how many vessels match, plus the number of filters applied. Its menu offers Export Data (CSV). [CONFIRM] exact CSV contents and file name (see report note).
  • The three-dot menu in the header holds the actions to change or delete the fleet. These are covered in separate articles.
