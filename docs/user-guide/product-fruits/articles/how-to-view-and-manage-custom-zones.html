See every custom zone you have created, search them by name, and open or edit any of them.

Steps

  1. Open Library and select the Zones tab.
  2. Click Custom Zones (next to the view selector). The Custom Zones page opens.
    • Shortcut: on the Library page, click Add, then under Create new choose Custom zone to go straight to the creation page.

    📷 Screenshot 1: Library Zones tab with the Custom Zones button

  3. Check the count at the top left, for example "12 Custom Zones".
  4. To find a zone, type in the Search by Name box. The list updates after you stop typing.

    📷 Screenshot 2: Custom Zones list with search box, New Custom Zone button and table

  5. Read the table columns: Name, Type, Updated and Actions.
  6. Click a zone's Name to open its zone page.
  7. To change a zone, click the three-dot icon in its Actions column and choose Edit.

    📷 Screenshot 3: Actions menu showing Edit

  8. To add another zone, click New Custom Zone (top right).

Expected result

The table lists your custom zones, 20 per page [CONFIRM: pagination controls and whether the list is capped]. While you search, the count reads for example 3 results for "gulf".

Good to know

  • The Type column shows the zone's shape (for example Polygon or Circle) [CONFIRM: exact wording shown].
  • Updated shows the date in a format such as 05 Oct 2026.
  • Columns cannot be sorted or filtered.
  • The Actions menu currently offers Edit only.
  • Breadcrumbs at the top (Library > Zones) take you back to the Library.
