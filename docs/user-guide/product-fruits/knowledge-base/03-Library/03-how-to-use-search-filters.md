# How to narrow down search results with filters

Use filters in the Add window to find the right vessel, port or zone faster.

## Steps
1. Open **Add** → **Vessel**, **Port** or **Zone** (see **How to add to your Library**).
2. Click **Filters** next to the search box. The panel opens, and a number badge shows how many filters are active.
   `[SCREENSHOT 1: Filters panel open for Vessels]`
3. Choose the filters you need:
   - **Vessels:** Flag, Type, Status, Deadweight (mt), Draught (m), Build Year (sliders)
   - **Ports:** Country, Type, Sub Type
   - **Zones:** Country, Type, Sub Type
4. Review the results list – it updates as you change filters.
5. Click **Reset All** to clear every filter.

## Good to know
- Picking a **Flag** (vessels) or **Country** (ports, zones) is enough to show results without typing a search term.
- Use the **×** in the search box to clear the text.
