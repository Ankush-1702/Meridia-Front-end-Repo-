# How to run PurpleTRAC screening on a vessel

Use the **PurpleTRAC screening** section to check a vessel against global sanctions watchlists and see an overall result.

## Before you begin
- This feature is available only if your account has PurpleTRAC screening access. Without access, the section shows **Unlock PurpleTRAC Screening** and **Available on request.** **[CONFIRM: which plan or licence grants access]**
- Open the vessel's page and stay on the **Overview** tab.

## Steps
1. In the left-hand vessel details panel, find the **PurpleTRAC screening** section.
   `[SCREENSHOT 1: Vessel details panel with the PurpleTRAC screening section collapsed]`
2. Select **PurpleTRAC screening** to expand it. The screening starts automatically.
3. Watch the progress messages, for example "Screening in progress...", "Checking sanctions watchlists..." and "Compiling compliance results...".
   `[SCREENSHOT 2: Screening in progress with spinner and message]`
4. If the check takes longer than a few seconds, you will see "You can leave this page - results will be saved."
5. When it finishes, read the badge next to **Overall**.
   `[SCREENSHOT 3: Overall result badge]`
6. To read more about the service, select **More about PurpleTRAC**. It opens in a new browser tab.

## Expected result
The **Overall** row shows one badge: **Ok** (green), **Warning** (amber), **Critical** (red) or **Unscored** (grey). **[CONFIRM: exact meaning of each result and what triggers Warning or Critical]**

## Good to know
- Hover over the help icon beside the section name for the tooltip: sanctions and compliance screening against global watchlists, powered by PurpleTRAC.
- There are no settings or filters for the screening in this section.
- The screening runs again each time you expand the section for a vessel that has no screening currently running. **[CONFIRM: whether each run is saved or counted against a screening allowance]**
- The code behind the screen says results are kept if you navigate away. **[CONFIRM: how long results are retained and where to find them later]**
- A box named **Get the full breakdown** says you can see every check behind the result (sanctions, PSC history, ship movement and more). It is marked **Available on request.** **[CONFIRM: how to request it]**
- If no result arrives within about 2.5 minutes, the section shows an error.

## Troubleshooting
| Problem | What to do |
|---|---|
| **Unlock PurpleTRAC Screening** appears | Your account lacks access. Select **More about PurpleTRAC** or contact your account team. |
| "PurpleTRAC screening is temporarily unavailable." | Select **Retry** to run the screening again. |
| Screening seems slow | Wait, or leave the page; the screen says results will be saved. |
| Result is **Unscored** | The screen gives no reason. **[CONFIRM]** |
