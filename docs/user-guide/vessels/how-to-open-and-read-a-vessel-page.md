# How to open and read a vessel page

Open a vessel in Meridia to see its details, recent movements on a map, and its events.

## Before you begin

- You need the vessel's IMO number or name, or the vessel must already be in your Library.
- Some sections in the vessel details panel depend on your access. See Good to know.

## Steps

1. Open **Library** from the main navigation.
2. Select the **Vessels** tab. **[CONFIRM]** how a vessel is found or selected from this tab (search box, list rows) because that screen is outside this page's code.
   `[SCREENSHOT 1: Library page with the Vessels tab selected]`
3. Select the vessel you want. The vessel page opens (its address ends with the vessel's IMO number).
   `[SCREENSHOT 2: Vessel page showing the header, tabs and map]`
4. Check the header. It shows a flag, the vessel name, and a line with the IMO, flag country and vessel type.
5. Use the breadcrumbs **Library** > **Vessels** above the name to go back.
6. Select the **Overview** tab to see the vessel details panel, the map, the replay bar and the toolbar.
7. In the vessel details panel, select a section heading to expand it. Sections are **Next Port**, **PurpleTRAC screening**, **MTI score**, **Dimensions**, **Registry** and **Ownership**.
   `[SCREENSHOT 3: Vessel details panel with the Dimensions section expanded]`
8. Select the **Events** tab to see the vessel's events in a table.
   `[SCREENSHOT 4: Events tab showing event type groups]`
9. On the **Events** tab, choose an event type. The types are **Area Arrival**, **Arrival**, **Departure**, **Area Departure** (Port Events), **Zone Entry**, **Zone Exit** (Zone Events), and **AIS Gap**, **STS Pairing**, **Positional Discrepancy**, **Port State Control** (Other Events).

## Expected result

You see the vessel's identity, its details, and its recent track and events.

## Good to know

- The top section of the details panel always shows **Type**, **IMO**, **MMSI**, **Flag**, **Callsign** and **Status**. **Flag since** appears only when a date is available.
- A dash (-) means no value is available for that field.
- **Dimensions** shows **LOA**, **Beam**, **Draught**, **Gross tonnage**, **Deadweight**, **Displacement** and **Service speed**.
- **Registry** shows **Built**, **Shipbuilder**, **Country of build**, **Hull type**, **Port of registry**, **Classification**, **P&I Club** and **DOC company**.
- **Ownership** shows **Operator**, **Registered owner**, **Technical manager**, **Ship manager** and **Group beneficial owner**. A company search icon appears next to a company name.
- **Next Port** shows **Destination** and **ETA**. **[CONFIRM]** the source and freshness of this data.
- **PurpleTRAC screening** and **MTI score** show an "Unlock" message if your account does not have access. **[CONFIRM]** the exact access wording for customers; the page says "Available on request."
- Open the three-dot menu in the header to choose **Add to Library** or **Remove from Library**.
- **Ask IQ** appears next to the tabs only if it is enabled for your account. **[CONFIRM]** availability.
- The header shows a refresh control. **[CONFIRM]** its label; it reloads the date range used for the map.

## Troubleshooting

| Problem | What to do |
|---|---|
| A loading placeholder stays on screen | Wait a moment, then reload the page. |
| An error page appears instead of the vessel | Check the IMO number in the address, then try again. **[CONFIRM]** exact error text. |
| A field shows a dash (-) | No value is held for that field. |
