# How to open and read a port page

Open a port in Meridia to see its live vessel activity, congestion analytics, berths and events.

## Before you begin

- The port must be findable through **Library** or **Search**, or already be in your Library.
- Some header features (for example **Ask IQ** and PurpleTRAC auto-screening in notifications) depend on your access. See Good to know.

## Steps

1. Open **Library** from the main navigation.
2. Select the **Ports** tab.
   `[SCREENSHOT 1: Library page with the Ports tab selected]`
3. Select the port you want. **[CONFIRM]** how a port is located on this tab (search box, list rows, add button) because that screen is outside this page's code. You can also use **Search** in the main navigation and pick a port from the results.
4. The port page opens (its address ends with the port's ID).
   `[SCREENSHOT 2: Port page showing the header, tabs and Overview]`
5. Check the header. It shows the country flag, the port name, and a subtitle in the form "Port, [country name]".
6. Use the breadcrumbs **Library** > **Ports** above the name to go back to your Library.
7. Select a tab to change what you see: **Overview**, **Congestion and Utilisation**, **Berths** or **Events**.
   `[SCREENSHOT 3: The four port tabs]`
8. On **Overview**, read the vessel counts, the map and the charts. See "How to view live port traffic on the map".
9. On **Congestion and Utilisation**, review the port's congestion analytics. **[CONFIRM]** the content of this tab, which is covered in a separate article.
10. On **Berths**, browse the port's berths. Select a berth to open its details, then select the back control to return to **Congestion and Utilisation**.
11. On **Events**, choose **Historic** or **Inbound Vessels**. Under **Historic**, the event types are **Area Arrivals**, **Arrivals**, **Berth Arrivals**, **Berth Departures**, **Departures** and **Area Departures**.
   `[SCREENSHOT 4: Events tab with event type options]`
12. To add the port to your Library, open the three-dot menu in the header and select **Add to Library**.
13. To remove it, open the same menu and select **Remove from Library**. If you have notifications on for the port, a **Remove from Library?** confirmation appears.
   `[SCREENSHOT 5: Three-dot menu showing Add to Library]`

## Expected result

You see the port's name and country, and can move between its Overview, Congestion and Utilisation, Berths and Events tabs.

## Good to know

- A confirmation message ("added to bookmarks" or "removed from bookmarks") appears after you add or remove the port.
- The notification (bell-style) control in the header is labelled **Manage Notifications**. Switch on **Enable Live Notifications** to choose the events to be notified about: **Area Arrivals**, **Arrivals**, **Departures** and **Area Departures**. Enabling notifications adds the port to your Library.
- **Auto-Screen Vessels** and the **SEVERITY** options (**Critical**, **OK**, **Warning**, **Unscored**) in notifications need PurpleTRAC Auto-Screening. If it is not enabled for you, the tooltip says to contact your account manager. **[CONFIRM]** exact email behaviour.
- **Ask IQ** appears next to the tabs only if your account or user is entitled to it. Selecting it opens Ask IQ with a prompt about this port.
- The header has no date range picker for ports.
- **[CONFIRM]** There is no port switcher on the page. To change port, use **Search**, **Library**, or select a vessel's port link elsewhere in the app.
- A **Details** tab exists in the code but is switched off in the current build, so it is not shown.

## Troubleshooting

| Problem | What to do |
|---|---|
| A loading placeholder stays on screen | Wait a moment, then reload the page. |
| An error page appears instead of the port | Check the port ID in the address, then try again. **[CONFIRM]** exact error text. |
| You cannot find the port in Library | Use **Search** in the main navigation, or add it from the **Ports** tab. |
