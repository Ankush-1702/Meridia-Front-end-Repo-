# How to add vessels to a fleet with filters

> UNPUBLISHED - do not release. The front end has no way to add vessels by filter. The filters exist only to narrow the vessel view on an existing fleet. Rules-based (dynamic) fleet creation is not reachable: the create page always passes the fleet type "static", and the dynamic wording in the preview panel is never shown.

If a filter-based guide is wanted, the accurate scope is "narrow the vessels shown in a fleet", which belongs with the fleet overview article.

## What exists today (fleet page, Overview)
- Filters named **Vessel Flag**, **Vessel Type**, **Vessel Class** and **MTI Score** (MTI shown only if the account has it). **[CONFIRM]** Options come from the fleet's own vessels.
- Choosing Vessel Types limits the Vessel Class options to those types.
- **Reset Filters** restores all options; "N filters applied" appears in the list header.
- "No vessels match these filters." with **Reset filters** appears when nothing matches.
- Filters change what you see only; they do not change the fleet's membership.
